# Per-ticket verification results

One file per implementation ticket, `IMPL-NN.md`, written by whoever completes the ticket: the
commands run, their actual results, the acceptance tests covered, and anything left unverified.
Ticket status lives in the GitHub issue linked from `docs/implementation-plan.md`. Results for
IMPL-01 and IMPL-02 are recorded in [verification.md](../verification.md).
